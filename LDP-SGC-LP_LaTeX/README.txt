Calibrated Bayesian Local Differential Privacy for Lightweight Learning Path Recommendation
Springer IJMLC submission -- LaTeX source package

Files
  main.tex        complete manuscript (generated by concatenating main_a.tex and main_b.tex)
  main_a.tex      preamble, front matter and Sections 1-4
  main_b.tex      Sections 5-8, declarations, appendices and \bibliography
  refs.bib        bibliography database (39 entries)
  sn-jnl.cls      Springer Nature LaTeX class (sn-jnl)
  sn-basic.bst    Springer basic numbered bibliography style
  figures/        Figures 1-7 as PDF (vector, for LaTeX) and PNG (raster, for Word)

Compilation
  pdflatex main
  bibtex   main
  pdflatex main
  pdflatex main

  main.tex uses \graphicspath{{figures/}}, so keep the figures directory next to it.
  Requires a TeX distribution with the sn-jnl class (or the local copy included here),
  booktabs, algorithm/algpseudocode, amsmath and natbib.

Notes
  - The class option line is: \documentclass[pdflatex,sn-basic,Numbered]{sn-jnl}
  - Figures were generated at the journal text width (12.4 cm) with matplotlib;
    the scripts are available from the authors on request.
