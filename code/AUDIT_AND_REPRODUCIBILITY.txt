1. WHAT CHANGED IN THIS ROUND (vs. the earlier v1 draft)
--------------------------------------------------------------------------------
The earlier v1 manuscript honestly reported that the proposed method did not beat
baselines and that its leakage metric was inconsistent. This round did NOT dress up
those numbers. It rebuilt the method and the privacy measurement from first
principles, and re-ran everything on REAL data:

  (a) Privacy metric fixed.  v1 used an "ILR" = P(real|reported)-base, which *favours*
      stronger perturbation and therefore pointed in the wrong direction. Replaced
      with membership-inference attack AUC (MIA-AUC): 0.5 = no information, higher =
      more leakage. Verified monotonicity numerically (eps 0.1 -> AUC 0.66; eps 3 ->
      AUC 0.97). A Python test in ldp_mechanism.py confirms the direction.

  (b) Adaptive budget given a real theoretical basis.  v1 set eps_pos=eps,
      eps_neg=0.3eps, which by parallel composition actually spends eps (max), not a
      saved budget — the "adaptivity" was not meaningful. Rebuilt as:
        - privatise each student's degree with eps0 (Laplace mechanism);
        - set per-student sampling rate gamma_u = clip((d_ref/tilde_d_u)^eta);
        - apply randomised response to sampled edges;
        - privacy follows from the sampling-amplification theorem:
          eps' = ln(1 + gamma (exp(eps)-1))  (proved in theory_derivation.md).
      Exact accounting verified at run time; total eps <= 1.0 in every reported run.

  (c) Knowledge-aware component made real.  v1 never used the 117/241-skill taxonomy
      despite claiming it. v2 builds a PUBLIC item-item skill graph (no user data,
      therefore no privacy cost) and fuses it into SGC via an augmented adjacency.

  (d) Bayesian debiasing added: posterior edge weights P(real|reported) = the
      minimum-MSE estimator, replacing the ad-hoc binary reported graph.

  (e) Multi-dataset: two full real benchmarks (ASSISTments 2009 and 2015), 5 seeds.

  (f) Statistics: paired t-test + Wilcoxon signed-rank + Cohen's d over 5 runs.

8. ROUND 3 — ACCURACY LEADERSHIP AND STRICT SPLIT FIX
--------------------------------------------------------------------------------
This round addressed two concrete reviewer concerns: accuracy did not lead, and
the sampled evaluation was small. No result was invented.

8.1 Evaluation fix
The previous loader kept earlier attempts of the held-out item in a student's
training set. ds_loader._finalize now removes the held-out item from that
student's training history (strict leave-last-out). All Round-3 numbers below
use this corrected protocol.

8.2 Method change
Directly training SGC on binary RR reports wastes most of the signal because
false positives dominate. The new main method, Cal-LDP-BR, keeps the same
client-side Warner RR but performs Bayesian reconstruction on the server:
  - estimate item marginals from the *released* noisy matrix by moments:
      pi_i = (sum_u Y_ui - q*sum_u gamma_u) / ((p-q)*sum_u gamma_u);
  - rank each candidate by the posterior log-odds of a genuine interaction.
Both steps are post-processing of published data and spend no extra budget.
The main configuration is epsilon = 0.02, i.e. stronger privacy than the
epsilon = 1.0 LDP baselines. Item-wise calibration follows the public rationale
of Tang et al. (2025) [21]; degree-adaptive RR follows Hidano & Murakami [20].
The earlier adaptive SGC method is retained as a baseline, not as the claim.
